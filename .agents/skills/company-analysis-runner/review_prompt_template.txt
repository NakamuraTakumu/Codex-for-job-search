Rules:
- If there are no meaningful issues, set `verdict: pass`.
- If any issue materially affects correctness or comparability, set `verdict: revise`.
- If `verdict: pass`, keep `findings` empty.
- If `verdict: revise`, include at least one concrete finding.
- Keep findings concrete and minimal.
- In `source_quality`, explicitly check whether unofficial sources are independent lineages rather than mirrors, reposts, or alternate surfaces of the same service, and whether `review_site`, `career_site`, and `forum` are being used for appropriate purposes.
